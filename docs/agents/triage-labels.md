# Triage 标签

各 skill 以五个标准 triage 角色交流。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义                                     |
| -------------------------- | ---------- | ---------------------------------------- |
| `needs-triage`             | `待分类`   | 维护者需要评估这个 issue                 |
| `needs-info`               | `待补充信息` | 等待报告者补充信息                     |
| `ready-for-agent`          | `可交代理执行` | 规格完整，可交给 AFK agent 自动执行 |
| `ready-for-human`          | `需人工实现` | 需要人类动手实现                      |
| `wontfix`                  | `不予修复` | 不会处理                                 |

当 skill 提到某个角色（如「打上 AFK 就绪的 triage 标签」）时，使用表中对应的本仓库标签字符串。
